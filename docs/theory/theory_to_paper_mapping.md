## 3. 建议的新论文总叙事

建议将论文的中心论证改写为：

> 离散 Offset 同时塑造通信释放负载和软件调用结构。显式命中表示下的带权 Offset 峰值决策即使在很窄的限制中仍为 NP-complete（T1），因此本文采用外层候选搜索；另一方面，固定 Offset 后的软件子问题具有可利用的 gcd/类型对称结构，相同 D 类型可整体压缩并以不同类型数 `m` 为参数精确 FPT 求解（T2）。该结构进一步使 `P*` 在当前 identity-symmetric 成本下经 D 直方图因子化（T3），可对外层的软件目标空间进行精确诊断。通信均衡与软件目标不存在一般单调一致性，最小两报文实例即可给出严格冲突（T4），故采用 Peak guardrail 下的双目标观测前沿。九网段完整 D 枚举与有限联合搜索分别承担“软件结构空间事实”和“已访问候选事实”，不能混为完整联合最优性。

这一叙事把“困难性”用于解释问题结构，把“可压缩性”用于解释精确内层，把“严格冲突”用于解释双目标方法，把“完整 D 枚举/观测前沿”用于区分两种实验口径。

### 4.1 可写入的正式结论

- 定义 Explicit Weighted Discrete Offset Peak Decision（EWDOPD）：输入显式给出每条报文的有限候选 Offset、每个候选命中的稳态时隙列表、整数权重和峰值阈值，问是否存在候选选择使所有时隙负载不超过阈值。
- EWDOPD 属于 NP，且即使限制为“相同周期、每条报文两个候选、两个稳态时隙、每候选命中一次”仍为 NP-complete。
- 相应峰值最小化问题为 NP-hard。
- 限制子类的证明由 `PARTITION` 归约，属于弱数值困难性证据。

### 4.2 前提

1. 命中列表是输入的一部分并显式列出；
2. 候选和权重为有限、可编码的离散量；
3. 阈值比较在输入长度的多项式时间内完成；
4. 结论针对 EWDOPD 的抽象权重，不自动覆盖物理 CAN FD 帧时间生成的更窄权重子类。

### 4.3 不证明什么

- 不证明 strong NP-hardness；
- 不证明隐式周期/超周期表示版本属于 NP；
- 不证明带真实 CAN FD `frame_time_us` 权重的限制子类仍 NP-hard；
- 不证明任何精确算法在工程规模上均不可用；
- 不证明“只能使用启发式”或 GCLS 是由复杂度唯一决定的。

### 4.4 正文与附录安排

- **正文**：第 3 章末给问题定义、一个定理、归约直觉和边界；约 0.75–1.0 页。
- **附录**：证书验证、`PARTITION` 构造、双向正确性和弱困难性说明；约 1.5–2.0 页。

### 5.1 T2-a：存在不拆分相同 D 类型的最优解

在当前组成本

`c(G) = (rho + |G|) / gcd_{i in G}(D_i)`，`rho > 0`

且成本不含 message identity 的前提下，至少存在一个全局最优分组，使相同 `D_i` 的报文不跨组拆分。该命题允许把报文级划分压缩为带重数的 D 类型划分。

**必须保留的限定**：这是“存在一个结构化最优解”，不是“每个最优解都结构化”；若组成本加入报文身份、不同增量成本、优先级或异质执行路径，该命题不自动成立。

### 5.2 T2-b：参数 `m` 下的 FPT

- `m` 为不同 D 类型数，而非报文数 `n`；
- 规范锚点 subset-DP 不重不漏枚举类型集合划分；
- 总时间写作 `O(3^m poly(|I|))`；
- 若每个状态仅保存最优值与前驱，空间为 `O(2^m poly(|I|))`；
- 当前实现为每个状态保存完整规范分组结构，每个状态的分组签名最坏包含 `O(m)` 个类型，因此空间为 `O(m 2^m poly(|I|))`；
- 因指数项只依赖 `m`，固定 Offset 分组在参数 `m` 下 fixed-parameter tractable；
- 这不表示对一般 `n` 多项式，也不表示 generic subset partition DP 是本文首创。

### 6.1 可写入的结构性质

对消息 `i`，令 `D_i=gcd(T_i,O_i)`。在固定输入事实和当前 identity-symmetric 组成本下：

1. `P*(O)` 先经 D 向量因子化；若两个 Offset 分配产生相同 D 向量，其最优软件代理成本相同。
2. 在报文身份不进入成本时，`P*` 进一步经 D 直方图因子化；排列相同 D 值不改变最优成本。
3. 可达 `D_i` 集合是 `T_i` 约数集合的子集，但不必包含全部约数，也不必构成子格。
4. 不同 D 直方图可以映射到相同 `P*`；直方图是充分统计量，不是 `P*` 的一一编码。
5. 一旦组成本含 identity-specific 参数，直方图充分性可能失效。
6. 可达 D 向量数、直方图数、`P*` 水平数和 Pareto 目标向量数存在依次不增的上界关系；这些是基数上界，不是可达性等式。

### 6.2 诊断口径

`d_structure_diagnostic_design.md` 的 exactness 必须原样继承：只有完整枚举全部可达直方图且精确评价全部 `P*` 才能称 `exact`。部分枚举不得把“已观察一个水平”升级为 `proven_constant_pstar`。只有 `fixed_d_vector` 或 exact 枚举得到单一水平时，才允许说软件目标在全部合法 Offset 空间内退化为常数。

### 7.1 可写入的结论

- `Qss(B) < Qss(A)`；
- `P*(B) > P*(A)`；
- 另两个分配分别与 B 对称或被 A 支配；
- 无 Peak guardrail，或 Peak guardrail 同时接纳 A、B 时，目标像的非支配集合恰含 A、B。

## 10. 摘要、贡献与结论的重写原则

### 10.1 摘要应包含

1. 研究对象和同一 Offset 的双侧耦合；
2. 显式命中模型的受限 NP-completeness，而非笼统“CAN Offset 优化 NP-hard”；
3. 当前代理成本下 same-D 存在性与参数 `m` 的 FPT；
4. D 直方图因子化和两报文严格冲突；
5. 九网段 exact D 结构结果与 observed front 结果分开；
6. exact inner / heuristic outer、未标定 `rho` 和观测前沿边界。

### 10.2 贡献列表建议六项

1. 明确定义通信侧离散带权时隙模型与软件侧代理模型；
2. T1：特定显式命中决策问题的受限复杂度；
3. T2：特定 identity-symmetric 成本的 same-D 压缩和 `m`-FPT 精确内层；
4. T3：`P*` 的 D 直方图因子化及 exact 结构诊断；
5. T4：特定两报文实例的严格冲突和 Peak guardrail 双目标方法；
6. 九网段 exact 结构枚举 + 有限预算 observed front 的分层实证。

### 10.3 结论应采用的证据动词

- 定理：证明、推出；
- 有限枚举：核验、交叉验证；
- 完整 D 诊断：精确枚举、确证该候选域内；
- 联合归档：观察到、在当前候选中；
- 工程机制：提示、支持解释；
- 不使用“证实所有实例”“完整揭示全局前沿”“证明工程最优”。

## 11. 正文与附录分配原则

正文只保留理解方法选择所必需的定义、定理、证明直觉和九网段聚合结果；附录保存可复核细节。建议：

- T1：定义与定理正文，归约附录；
- T2：same-D 命题和 FPT 定理正文，交换/归纳证明附录；
- T3：因子化命题与九网段聚合正文，反例、上下界和诊断状态机附录；
- T4：两点冲突结论正文，四分配/全部划分表附录；
- 141/141：正文仅作为实现核验一句话，输入表和脚本口径放附录；
- provenance、hash、cap/timeout 细节放附录，但正文必须保留“exact/observed”的差异。

## 13. 两种入稿方案及页数估计

### 方案 A：最小侵入式整合

- 保持九章结构；
- T1 在第 3 章末占短定理；T2/T3 合并进第 5 章；T4 置第 6 章开头；
- 九网段 D 结构只加一张表；完整证明全部入附录；
- 预计正文增加 3.5–4.5 页，附录增加 3.5–4.5 页，总计约 7–9 页。

**优点**：改动小，适合快速投稿版本。
**缺点**：理论贡献仍可能被读作对工程算法的补注，复杂度—结构—联合权衡主线不够突出。

### 方案 B：理论主线式整合（推荐）

- 保持现有章节编号但重写引言、相关工作和贡献；
- 第 3–6 章分别承担 T1、T2/T3、T4 和分层求解的递进关系；
- 第 7 章新增完整 D 结构 RQ，显式分离 exact structural space 与 observed joint front；
- 讨论与结论按证据层级重排；
- 预计正文增加 5–6.5 页，附录增加 4–5.5 页，总计约 9–12 页。

**推荐理由**：T1–T4 不是四个孤立附录结论，而是恰好解释现有算法架构的四个环节。方案 B 能把“为什么外层搜索、为什么内层精确、为什么可做结构诊断、为什么需要双目标”串成一个可审稿的理论故事，同时保留工程论文的九网段证据。

### 13.1 客观比较

| 维度 | 方案 A：最小改动 | 方案 B：推荐重构 |
|---|---|---|
| 理论清晰度 | 中；结论可见但主线仍偏工程模块串联 | 高；困难外层—精确内层—内生耦合形成闭环 |
| 修改成本 | 低到中 | 中到高，主要是引言、章首章末和交叉引用重排 |
| 页数增加 | 约 7–9 页 | 约 9–12 页 |
| 答辩理解难度 | 初稿短，但答辩时需口头补足理论关系 | 文稿更长，但答辩叙事更直观、证据层级更清楚 |
| 学校模板兼容性 | 高，几乎不动章节骨架 | 高，仍保留九章与现有附录，只调整小节组织 |
| 后续投稿价值 | 中；适合本科初稿快速返修 | 高；适合作为最终毕业论文和后续论文底稿 |

**最终选择：方案 B。** 它不改变算法和实验，只重排论证；新增成本主要是文字与证明组织，换来更清晰的理论定位和更低的新颖性/过度宣称风险。
