# CAN FD Offset Optimizer v1.2 发布说明

发布日期：2026-10-29。

## 时隙与报文明细

此前明细默认只列出同时释放 4 帧及以上的拥挤时隙，无法直接比较帧数较少但保守占用
时间更长的时隙。1.2 默认显示全部有报文时隙，并按真实时隙分组。

- 组头显示原始或优化后状态、真实时间范围、帧数与时隙总保守占用时间。
- 保留报文名称、CAN ID、长度、周期、Offset、权重负载、单帧保守占用时间与提示。
- 帧数筛选独立提供全部有报文时隙、4 帧及以上、仅 4 帧和 5 帧及以上。
- 时隙总保守占用时间和时隙内单帧保守占用时间分别提供不排序、升序与降序，可同时
  启用；默认均为不排序。排序按数值进行，相同值保持原序，恢复不排序还原对应层原序。
- 表头不再逐行排序，避免拆散时隙分组。

点击热力格或任一明细行会定位到该时隙，显示全部真实释放记录，包括少于 4 帧的时隙；
空时隙显示明确提示。单时隙模式暂时禁用帧数筛选和时隙排序并保留值，单帧排序仍可用。
点击“返回全部时隙”恢复此前设置。切换网段、启动或稳态窗口、重新绑定结果会清除
时隙选择，并保留当前界面会话中的筛选与排序偏好。

## 时间口径与未知值

时隙总时间继续使用项目正式保守占用时间估算，按该时隙的每次帧释放求和，同一报文
多次释放不会去重。该值独立于优化权重，不使用长度或优化权重代替。

缺失时间显示“—”，合法的 0 正常显示。部分报文可计算的时隙只显示已知时间下界，
并说明已知帧数，例如“≥180 μs（已知 1/2 帧）”。不完整时隙在升序和降序中都排在
完整可计算时隙之后，彼此保持原序；组内未知单帧时间始终排在最后。

## 便携包

发布 Windows x64 便携包 `CANFDOffsetOptimizer-1.2-win-x64.zip` 及 SHA256 校验文件。
请完整解压到可写目录后运行 `CANFDOffsetOptimizer.exe`，无需安装 Python。内置默认
配置随包提供，用户输入和输出位于程序旁的 `user_input`、`user_output` 目录。

## 已知边界

本次只改变结果明细展示。热力图时间顺序、帧数颜色、核心负载、优化权重、搜索目标、
DBC 回写及计算结果保持既有语义。保守时间是协议级估算，不代表实际总线测量值。

本次未修改 PTBUS2 时隙配置、自动超周期或优化算法。含 2 ms 周期的 PTBUS2 仍需显式
配置合适时隙，例如 `slot_ms: 1`；默认 5 ms 时隙的对齐限制仍然存在。

源码安装的依赖范围尚未限定 cantools 上界，cantools 45.1.2 无法解析项目中部分既有
DBC 样例。本便携包使用经全量回归验证的 cantools 40.7.1；本次未修改 DBC 解析语义。
